# AGENTS.md

Канон проекта — в [ROOT.md](ROOT.md). Прочитай его перед работой: там навигация по
репозиторию, что запускать перед сдачей хода и правила, которые нельзя нарушать молча.

Этот файл намеренно не дублирует ROOT.md — он существует, чтобы агент, который ищет
`AGENTS.md`, нашёл дорогу.

## Перед тем как открыть PR

Бюджет ревью — примерно **600 строк бизнес-логики на PR**. Сгенерированный код, тесты,
документация, DDL, форматирование и механические перемещения файлов в бюджет не входят.
Больше — режь на слайсы и неси их по очереди.

Что должно быть в описании PR и в теле каждого коммита, чтобы по ним можно было принять
решение о мерже, — [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).
