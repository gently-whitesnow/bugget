# ROOT — точка входа для агента

Навигация по репозиторию и правила прохода. Здесь только ссылки и то, что нигде больше
не записано: содержимое README и ADR не дублируется.

## Миссия

Bugget — инструмент для баг-репортов: тестировщик заводит репорт, разработчик видит шаги,
факт и ожидание, переписка и вложения лежат рядом с багом. Self-hosted, MIT.
Что внутри, как поднять и как настроить — [README.md](README.md).

Продуктом пользуются у заказчика, и у API ровно один клиент — фронтенд этого же
монорепозитория. Отсюда главное ограничение: **публичный HTTP-контракт ломать нельзя.**
Если ломаем — фронт и бекенд правятся одним PR, решение фиксируется ADR.

## Что запускать перед сдачей хода

```sh
./scripts/quality/verify.sh          # всё, это же гоняет CI
./scripts/quality/verify.sh --fast   # без медленных гейтов, для цикла разработки
./scripts/quality/verify.sh --list   # какие гейты вообще есть
```

Флаги и поведение раннера — `verify.sh --help`. Набор гейтов правится в
`.quality/quality.config.json`, не в скрипте и не в workflow.

## Правила, которые нельзя нарушать молча

**Падает гейт — чини причину, а не гейт.** `enabled: false`, задранный baseline,
закомментированное правило, новый `#pragma warning disable` — допустимы только с явным
обоснованием в теле коммита. Причина — ADR-0002.

**`*.g.cs` руками не правим.** Источник правды — `specs/contracts/**/openapi.yaml`,
перегенерация — `scripts/quality/openapi-generate.sh`. Причина — ADR-0005.

**Новый код пишется по DDD.** Rich-модель и агрегаты для нового; легаси мигрируем только
при касании. Причина — ADR-0003.

**Граф проектов остаётся DAG**, `Domain` и `Application` не зависят от persistence,
транспорта и ASP.NET. Целевая раскладка — ADR-0001.

**Reuse-first.** Новый эндпоинт, схема в контракте, stored function, колонка или таблица —
последний вариант, а не первый. Сначала проверь, нет ли подходящего.

**Схема БД в текущей программе работ не меняется.**

## Дисциплина PR

Бюджет ревью — примерно 600 строк бизнес-логики на PR. Сгенерированный код, тесты,
документация, DDL, форматирование и механические перемещения файлов в бюджет не входят.
Больше — режь на слайсы.

Не угадывай молча: если требование читается двояко, затрагивается схема БД или публичный
контракт, или предпочтительнее решение, отличное от запрошенного, — скажи об этом до того,
как напишешь код.
