---

Как заводить новый ADR:

1. Скопировать этот файл в `adrs/NNNN-kebab-заголовок.md`, номер — следующий
   свободный четырёхзначный, сквозной по каталогу.
2. Заполнить. ADR описывает решение и причину, а не инструкцию — инструкции живут
   в README и `AGENTS.md`. Форму держит `harness check --only adrs.shape`: раздел
   `## Статус` первым (строка `Дата:` и строка статуса), H2 только `Контекст`,
   `Решение`, `Последствия` (обязательны), `Альтернативы`, `Ссылки`; прочие подразделы —
   H3. Лимиты: 1000 слов, 10 строк кода в fenced-блоках, 12 строк в таблице; больше —
   разбить решение на несколько ADR.
3. Добавить строку в `adrs/REGISTRY.md`.
4. ADR не редактируют задним числом: устаревшее решение получает статус
   `Superseded by ADR-NNNN`, а новое пишется отдельным файлом.
