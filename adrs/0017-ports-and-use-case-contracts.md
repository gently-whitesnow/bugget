# ADR-0017: Порты внешних зависимостей и контракты use-case прикладного слоя

- **Статус:** Accepted
- **Дата:** 2026-09-17
- **Решение принял:** владелец продукта

## Контекст

Правила жили прозой в `ROOT.md` и принуждались архитектурными тестами. `ROOT.md`
свёрнут в `AGENTS.md` (ADR-0016), а обоснование правил обязано пережить навигацию.

## Решение

Оформлять вызываемые внешние зависимости Application портами, а use-case выпускать за
границу слоя только через интерфейс.

- **Порт** — интерфейс внешней зависимости, которую Application вызывает: у него есть
  хотя бы одна собственная операция, и его реализует адаптер из `Infrastructure` или
  транспорта. Порт живёт в `Bugget.Application/**/Ports`. Интерфейс из одних
  property-getters (например `IExternalSearchItem`) портом не является и остаётся рядом
  со своей моделью. Внутренние сервисы и оркестрационные интерфейсы портами механически
  не становятся.
- Persistence-порт Postgres называется `I*DbClient`; зависимость, которая в БД не ходит,
  называется по возможности (`IUserCacheInvalidator`).
- **Use-case:** `Bugget.Api` и `Bugget.Infrastructure` получают application-сервис через
  интерфейс из `Bugget.Application`, конкретный класс выбирает только DI-композиция.
  Интерфейс лежит рядом с реализацией (`Services/<Модуль>/`). Внутри слоя коллаборатор
  живёт классом, пока нет второго потребителя или подмены в тестах.
- `Bugget.Application/Users/**` массово не переносится, мигрирует при касании (ADR-0003).

## Последствия

- Правила и фикстуры — в `backend/Bugget.Architecture.Tests/NamingConventionRulesTests.cs`;
  правило use-case накрывает все типы `Bugget.Api`, исключение — поимённый список
  `Quartet.CompositionRoot`.
- Расхождения с целевым графом записаны поимённо в `KnownDeviations.cs` со ссылкой на
  ADR. Список только сокращается; снятое отступление обязано исчезнуть из списка.

## Отброшенные альтернативы

- **Интерфейс на каждый класс Application:** шум без второго потребителя.
- **Отдельный каталог контрактов use-case:** разводит интерфейс и реализацию.
