## Скрепка принимает файлы любого типа

Бэкенд пропускает только белый список MIME (`backend/Bugget.Domain/Constants/AttachmentConstants.cs`):
картинки, видео, gif, текстовые форматы. Скрепка и вставка в `ComposerInput` берут любой
файл, поэтому о неподходящем типе, например PDF, пользователь узнаёт только после отправки.

Что сделать:

- Ограничить `<input type="file">` через `accept` тем же списком.
- Проверять тип при вставке из буфера и сразу объяснять, что файл не поддерживается.
- Решить, нужен ли PDF: сейчас его нет в белом списке, причина нигде не записана.
