---

Как заводить новый ADR:

1. Скопировать этот файл в `specs/ADR/NNNN-kebab-заголовок.md`, номер — следующий
   свободный четырёхзначный, сквозной по каталогу.
2. Заполнить. ADR описывает решение и причину, а не инструкцию — инструкции живут
   в README и `ROOT.md`.
3. Добавить строку в `specs/ADR/REGISTRY.md`.
4. ADR не редактируют задним числом: устаревшее решение получает статус
   `Superseded by ADR-NNNN`, а новое пишется отдельным файлом.
