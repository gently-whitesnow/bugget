# ADR-0004: Отказ от Monade и Flow в пользу нативных кортежей

- **Статус:** Accepted
- **Дата:** 2026-07-26
- **Решение принял:** владелец продукта

## Контекст

В бекенде две параллельные реализации одного и того же — Result-монады:

- `backend/Monade` — 52 строки, отдельный csproj;
- `backend/Flow` — 305 строк, отдельный csproj, включая `Flow/Errors/*` и ASP.NET-обвязку.

Вместе они используются примерно в 70 файлах (`using Monade` — 30, `using Flow` — 41).
То есть в проекте два разных способа вернуть ошибку, и выбор между ними определяется
тем, из какого модуля вырос код, а не смыслом. Обе библиотеки — самописные, без
экосистемы вокруг: ни анализаторов, ни привычного читателю API.

## Решение

Убрать `Monade` и `Flow`. Возврат «результат или ошибка» — нативным кортежем C#:

```csharp
var (report, error) = await _reports.GetAsync(id, ct);
if (error is not null)
    return error;
```

- Один способ возврата ошибки на весь бекенд.
- Никакой обёртки, никакого csproj: кортеж — язык, а не библиотека.
- ASP.NET-обвязка из `Flow` (middleware, маппинг ошибок в HTTP) переезжает в `Api`
  как обычный код слоя, а не как отдельная библиотека (см. ADR-0001).

Миграция режется на 2-3 PR по модулям — за один PR ~70 файлов не проходят по бюджету ревью.

## Последствия

- Минус два csproj и ~360 строк инфраструктурного кода.
- Пропадает цепочечный composition-стиль (`.Then(...).Map(...)`), где он был.
  Это принято: явная проверка ошибки читается новым человеком и агентом без изучения
  библиотеки.
- Публичный HTTP-контракт не меняется: формат ошибки на проводе остаётся прежним
  (`ErrorResponse`, см. `specs/contracts/shared.yaml`). Это чисто внутренний рефакторинг.
- Пока миграция не завершена, в репозитории три способа возврата ошибки вместо двух.
  Поэтому слайсы идут подряд, а не вперемешку с другими задачами.

## Отброшенные альтернативы

- **Оставить одну из двух и выпилить вторую.** Дешевле, но сохраняет самописную
  библиотеку без экосистемы; решение владельца — нативные кортежи.
- **Взять готовую библиотеку (LanguageExt, ErrorOr, OneOf).** Внешняя зависимость и
  своя кривая обучения ради того же результата, который даёт синтаксис языка.
- **Исключения вместо возврата ошибки.** Меняет поведение и стоимость на горячем пути,
  выходит далеко за рамки рефакторинга.
